## Manual VM Setup: Ubuntu and CentOS

This section provides a comprehensive guide on how to manually set up virtual machines using Ubuntu and CentOS operating systems. Each subdirectory contains detailed instructions, configurations, and optional troubleshooting tips for setting up and reviewing these environments, primarily within Oracle VirtualBox.

The aim is to understand the installation process, explore system configurations, and establish a clean, working VM environment suitable for DevOps-related practices.
